# Chợ Tốt 한국어 오토바이 등록폼

Chợ Tốt의 차량 등록 화면(category_group=3, ia_version=3)에서 오토바이 사진 업로드 후 표시되는 폼을 한국어로 재구성한 독립 프런트엔드입니다.

- 사진 최대 20장, 동영상 1개 추가·삭제·순서 변경
- 판매글 설명, 제목, 가격, 주소, 판매자 유형
- 차량 서류, 중고/신차, 제조사, 모델명, 연식, 종류, 주행거리, 배기량, 원산지, 보증
- 필수 입력 검사, 미리보기, 사진을 포함한 IndexedDB 임시 저장·복원
- 입력 내용 JSON 다운로드, PC·모바일 대응

## 범위

실제 Chợ Tốt에 판매글을 전송하거나 로그인하지 않습니다. 가격 단위는 원본의 VND입니다. 주소는 직접 입력하며 제조사·모델·차량 종류는 자유 입력입니다. AI 기능은 로컬 설명 작성 양식으로 대체했습니다. 다른 차량 카테고리는 구현 범위에 포함되지 않습니다.

사진과 서류는 브라우저 메모리에서 사용하고, 사용자가 임시 저장을 누르면 해당 브라우저의 IndexedDB에 저장합니다. 서버에 업로드하지 않습니다. 사용자 사진·계정·채팅·알림 정보는 저장소에 포함하지 않습니다.

## 실행 및 배포

```sh
npm ci
npm run dev
npm run build
```

GitHub Pages는 GitHub Actions에서 빌드한 `dist/client`를 배포합니다. 상대 경로 설정으로 저장소 하위 경로에서 실행할 수 있습니다.

## 출처 및 자산

원본: https://www.chotot.com/dang-tin?category_group=3&ia_version=3

로고와 업로드 아이콘은 원본 페이지에서 확인한 Chợ Tốt 자산이며 해당 권리는 원권리자에게 있습니다. 한국어 글꼴은 Noto Sans KR(SIL OFL), 일반 UI 아이콘은 Lucide(ISC)입니다. 원본 Reddit Sans는 한국어 지원과 자산 다운로드 제한으로 Noto Sans KR로 대체했습니다. 공식 Chợ Tốt 서비스가 아닙니다.

첫 접속부터 사진, 설명, 제목, 가격, 주소와 모든 오토바이 상세 항목을 표시합니다. 사진·설명을 먼저 입력하지 않아도 전체 폼을 볼 수 있습니다.
