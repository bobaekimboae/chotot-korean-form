# Chợ Tốt 한국어 차량 등록폼

원본 차량 등록 페이지의 6개 카테고리를 한국어로 재구성한 독립 프런트엔드입니다. 첫 접속부터 전체 폼이 열리며, 상세 정보의 카테고리를 변경하면 입력 항목과 필수 검사가 함께 바뀝니다.

| 카테고리 | 주요 상세 항목 |
| --- | --- |
| 오토바이 | 제조사, 모델, 연식, 종류, 주행거리, 배기량, 원산지, 보증 |
| 자동차 | 제조사, 모델, 연식, 변속기, 연료, 좌석 수, 차체 형태, 색상, 주행거리, 중고차 추가 정보 |
| 트럭 / 덤프트럭 | 트럭 제조사, 적재량, 연식, 연료, 원산지, 색상, 주행거리 |
| 자전거 | 제조사, 종류, 원산지, 색상, 프레임 크기·소재, 보증 |
| 기타 차량 | 종류, 연식, 연료, 원산지, 색상, 보증 |
| 차량 부품 | 부품 종류, 원산지 |

카테고리를 바꾸어도 공통 사진·설명·제목·가격·주소는 유지됩니다. 상세 값과 서류는 카테고리별로 보관하며 돌아오면 복원됩니다. 미리보기 및 JSON 다운로드에는 현재 카테고리의 표시 항목만 포함합니다. 신차에서는 중고차용 항목을 숨기고 검사 대상에서도 제외합니다.

- 사진 최대 20장, 동영상 1개 추가·삭제·순서 변경
- 미리보기, 필수 검사, IndexedDB 임시 저장·복원
- PC·모바일 지원 및 입력 내용 JSON 다운로드
- `?category=truck`으로 트럭 폼 직접 열기 (car, motorcycle, bicycle, other, parts 지원)

## 범위와 저장

실제 Chợ Tốt 로그인·AI·판매글 게시 API에는 연결하지 않습니다. 가격은 VND이며 주소, 제조사·모델과 일부 상세 값은 직접 입력합니다. AI 대신 설명 양식을 제공하는 기존 보조 화면이 포함되어 있습니다. 원본의 전체 제조사/모델 및 주소 데이터베이스를 복제하지 않습니다.

사진과 서류는 브라우저에서만 사용하고 임시 저장 시 해당 브라우저의 IndexedDB에 저장합니다. 서버에 업로드하지 않습니다. 사용자 사진·계정 정보는 저장소에 포함하지 않습니다.

## 개발 및 배포

```sh
npm ci
npm run dev
node --test tests/categories.test.mjs
npm run build
```

GitHub Actions가 `dist/client`를 GitHub Pages에 배포합니다. 카테고리별 스키마와 검사는 `src/categories.js`에서 관리합니다.

## 출처

원본: https://www.chotot.com/dang-tin?category_group=3&ia_version=3

원본 로고·업로드 아이콘의 권리는 Chợ Tốt에 있습니다. 한국어 글꼴은 Noto Sans KR(SIL OFL), 일반 UI 아이콘은 Lucide(ISC)입니다. 공식 Chợ Tốt 서비스가 아닙니다.
